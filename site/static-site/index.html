Features

Everything you need,
nothing you don't

Nub augments your existing Node.js workflow with speed and safety. Drop-in replacements for the tools you already use.

01

TypeScript Runtime

Run .ts, .tsx, and .jsx files directly on stock Node. Full tsconfig support, decorators, and modern syntax.

nub index.ts
02

Fast Script Runner

Drop-in for npm run and pnpm run. Lifecycle hooks, env vars, and workspace support minus the JavaScript startup cost.

nub run build
03

CLI Launcher

Resolves node_modules/.bin in Rust and executes directly. No wrapper process means commands feel instantaneous.

nubx eslint .
04

Package Manager

Built-in, pnpm-compatible package manager. Reads your existing lockfile, hardened against supply-chain attacks.

nub install
05

Node Version Manager

Reads .node-version or .nvmrc and installs the right Node from nodejs.org. Replaces nvm and fnm.

nub node install 22
06

Supply-Chain Safety

Deny-by-default build scripts, OSV vulnerability checks, and trust verification — all enabled out of the box.

safe by default
