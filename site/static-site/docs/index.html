Introduction

Nub is an all-in-one toolkit for Node.js. It augments your existing Node workflow instead of trying to replace it.

What Nub Does

Nub provides four core capabilities:

  • File Runner — Run TypeScript and JSX files directly on stock Node
  • Script Runner — A 24× faster drop-in for pnpm run
  • CLI Launcher — A 19× faster drop-in for npx
  • Package Manager — A built-in, pnpm-compatible package manager

Installation

Install Nub with a single command:

# macOS / Linux
curl -fsSL https://nubjs.com/install.sh | bash

# Windows
powershell -c "irm https://nubjs.com/install.ps1 | iex"

# Homebrew
brew install nubjs/tap/nub

# npm
npm install -g --ignore-scripts=false @nubjs/nub

Quick Start

Once installed, you can immediately start running TypeScript files:

# Create a TypeScript file
echo 'console.log("Hello from Nub!")' > hello.ts

# Run it with Nub
nub hello.ts

Zero Lock-in

The most important thing about Nub is what it doesn't add:

  • No Nub global
  • No nub: module namespace
  • No @nub/* npm scope
  • No "nub" field in package.json
  • No nub-named lockfile

Your code runs on stock node. Nub simply transpiles your code, polyfills missing global APIs, sets some flags, and makes additive modifications to Node's module resolution to improve TypeScript support.
