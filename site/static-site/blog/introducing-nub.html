Introducing Nub

The all-in-one JavaScript toolkit that augments Node.js instead of trying to replace it.

Why Nub?

The JavaScript ecosystem has a tooling problem. Every year brings new runtimes, new package managers, and new build tools — each promising to be the silver bullet. But the reality is that most teams just want their existing Node.js workflow to be faster, safer, and more ergonomic.

Nub takes a different approach. Instead of replacing Node.js, it augments it. You get TypeScript support, faster script execution, a built-in package manager, and Node version management — all without switching your runtime or your habits.

The Toolkit

Nub is organized around four core commands:

nub <file> — TypeScript-first Node.js

Run .ts, .tsx, and .jsx files directly on stock Node with full support for tsconfig.json, .env loading, decorators, and modern syntax. Nub transpiles your code in memory using Rust (via oxc) and runs the output on the real node binary.

nub run — 24× faster pnpm run

A drop-in for npm run and pnpm run with lifecycle hooks, env vars, and workspace support — minus the per-call JavaScript startup these tools pay on every invocation.

nubx — 19× faster npx

Resolves node_modules/.bin in Rust and executes the binary directly. No Node process in the wrapper means commands feel instantaneous.

nub install — A built-in package manager

A pnpm-compatible package manager that reads your existing lockfile (pnpm, npm, or bun), writes the same format back, and is hardened against supply-chain attacks out of the box.

Zero Lock-in

The most important thing about Nub is what it doesn't add:

  • No Nub global
  • No nub: module namespace
  • No @nub/* npm scope
  • No "nub" field in package.json
  • No nub-named lockfile

Your code runs on stock node. Nub simply transpiles your code, polyfills missing global APIs, sets some flags, and makes additive modifications to Node's module resolution to improve TypeScript support.

Getting Started

Install Nub with a single command:

$ curl -fsSL https://nubjs.com/install.sh | bash

Then run your TypeScript files directly:

$ nub app.ts
Hello, world!

That's it. No build step, no configuration, no new runtime. Just fast, modern JavaScript development on the Node.js you already know.

What's Next

We're just getting started. Nub 0.5.0 is the foundation — a fast, safe, compatible toolkit that augments Node.js. In the coming months, we'll be focused on:

  • Expanding TypeScript support
  • Improving package manager compatibility
  • Adding more polyfills for modern APIs
  • Better integration with existing tools and workflows

We believe the future of JavaScript tooling isn't about replacing what works — it's about making it better. Nub is our contribution to that future.
